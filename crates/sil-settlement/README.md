# sil-settlement

Autorisation par les signatures des approbateurs, outbox idempotente et reprenable, garde d'escrow, chaîne simulée avec pannes (`testing`).

Dépend de : `sil-ledger`, `sil-chain-core`, `sil-crypto`, `sil-codec`. Pas de client Solana : un adaptateur implémente `Chain`.
