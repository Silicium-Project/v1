# sil-control-api

API HTTP de contrôle : jetons à scopes en temps constant, limites de débit et de taille, contenu envoyé en octets (jamais un chemin), OpenAPI généré de la table des routes.

Dépend de : `sil-types`, `sil-crypto`, `sil-quota`. Ne connaît pas le nœud (trait `Backend`).

Doc technique : ../../docs/technical/security/control-api.md
