# Démarrage rapide

Pour un poste de travail (votre machine calcule) : installez l'application de bureau, liez la
machine à votre compte, puis activez-la.

1. Téléchargez `Silicium_0.1.0_x64-setup.exe` sur le site (ou le `.deb` / l'AppImage Linux), vérifiez
   sa somme SHA-256, puis installez-le.
2. Sur le site, ouvrez **Machines**, générez un code de liaison, puis cliquez sur **Lier cette machine**.
   Détails : [desktop-app.md](desktop-app.md).
3. Ouvrez **Tableau de bord** dans l'application et cliquez sur **Activer mon PC**.

Pour soumettre un calcul : connectez-vous avec votre wallet Solana sur le site, ouvrez **Soumettre**,
choisissez le type de calcul et le fichier. Chaque type a un fichier d'exemple sur la page **Types de
calcul** du site.

Pour faire tourner un nœud sans application (serveur, test) : [run-a-node.md](run-a-node.md).
